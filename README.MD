# Прототип браузерной RTS (задача 2)

За основу взят [PR #35](https://github.com/reznikovkg/vue-rts/pull/35) (изометрическая карта на SVG),
структура проекта и Vuex-модуль - по образцу [PR #45](https://github.com/reznikovkg/vue-rts/pull/45)
и [PR #36](https://github.com/reznikovkg/vue-rts/pull/36).

## Толстопятов Владислав 
* Фреймовый подход и очередь событий ([PR #2](https://github.com/anoddyne/vue-rts/pull/2)):

Мир в сторе разделён на элементы карты (текущая действительность: позиции, здоровье) и события
(приказы); каждый кадр - это применение текущих событий к элементам (`src/game/events.js`), а
перемещение переписано на `stepToward` с результатом MOVING / DONE / BLOCKED. Появилась очередь
маршрута: Shift+ПКМ дописывает точку, обычный ПКМ заменяет маршрут целиком, весь путь рисуется
пунктиром.

## Бесшапошников Владимир 
* Множественное выделение ([PR #3](https://github.com/anoddyne/vue-rts/pull/3)):

Клик по объекту выделяет его, Shift+клик добавляет или убирает из выбора; рамка выделяет группу
юнитов, Shift+рамка добавляет её к уже выбранным. ПКМ отправляет всех выбранных юнитов строем
вокруг точки клика.

* Группы, сценарии, пауза и конец игры ([PR #4](https://github.com/anoddyne/vue-rts/pull/4)):

У юнитов и зданий появилось поле `group` - группы различаются цветом обводки на карте и подписью
в панели выбора. В меню запускаются подготовленные сценарии («Песочница», «Дуэль», «Три группы»),
камера при старте встаёт на базу первой группы. Пробел или кнопка в углу карты ставит паузу: мир
замирает, камера продолжает работать. Игра заканчивается, когда объекты остались только у одной
группы, - поверх карты появляется оверлей «Победила группа N» с кнопками «Заново» и «В меню»
(проверка выполняется после каждого кадра и заработает, как только в игре появятся смерти объектов).
* Обход препятствий ([PR #5](https://github.com/anoddyne/vue-rts/pull/5)):

Приказ движения прокладывает маршрут вокруг зданий: A* по сетке шага gridSize со сглаживанием
(`src/game/pathfinding.js`). Путь вычисляется один раз при старте события от реальной позиции юнита
и живёт внутри этого же события (очередь Shift+ПКМ учитывается), клик внутрь здания ведёт в
ближайшую достижимую точку. Точки обхода видны на пунктирном маршруте.
